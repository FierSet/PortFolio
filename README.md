# Portfolio

A personal portfolio web application showcasing projects, skills, and experiences. Built with **ASP.NET Core MVC** and deployed on Azure.

## 🌐 Live Demo

**[Visit Portfolio](https://portfolio-miguelortega-g5afh4dnhxg2d2a8.mexicocentral-01.azurewebsites.net/)**

## 📋 Features

- **Responsive Web Design** - Clean, modern portfolio interface
- **AI Integration** - ChatGPT integration for intelligent interactions
- **Multi-language Support** - Support for multiple languages
- **Project Showcase** - Display and manage portfolio projects
- **Contact Section** - Get in touch functionality

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|---------|
| **ASP.NET Core 9.0** | Web framework |
| **C#** | Backend language |
| **Razor Views** | UI templating |
| **JavaScript** | Frontend interactivity |
| **SQLite** | Database |
| **Bootstrap** | CSS framework |
| **Azure** | Cloud hosting |

## 🚀 Getting Started

### Prerequisites
- .NET 9.0 SDK or later
- Visual Studio or VS Code

### Installation

```bash
# Clone the repository
git clone https://github.com/FierSet/PortFolio.git

# Navigate to project directory
cd PortFolio

# Restore dependencies
dotnet restore

# Run the application
dotnet run
```

The application will be available at `https://localhost:5001`

## 📁 Project Structure

PortFolio/
